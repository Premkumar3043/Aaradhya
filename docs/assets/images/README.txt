Temple photography is wired to Wikimedia Commons thumbnails in js/data.js so the ZIP stays lightweight. The authors, source pages and licences are listed in ../../PHOTO_CREDITS.md. The browser needs an internet connection to show the photos. The original SVG illustrations in js/art.js remain as fallbacks.

To self-host a photo instead, download a copy only after reviewing the source file's licence and attribution requirements, save it here using the matching temple ID (for example tirumala.jpg), then change the matching TEMPLE_PHOTOS URL in js/data.js to assets/images/tirumala.jpg.


`lotus-rings.webp` is a transparent water-light texture derived from the lotus artwork supplied for the intro. It is layered behind the animated SVG lotus; the flower itself is drawn and animated in `index.html` and `js/animations.js`.
